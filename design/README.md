# Design Directory

All design work for Atomic Adventures lives here.

## Contents

| Folder | Purpose |
|--------|---------|
| **docs/** | Core design documents — game design, story, narrative |
| **tech/** | Simulation specifications — hydro, PV, nuclear, fusion |
| **content/** | Learning objectives, progression, roadmap |
| **art/** | Story art, concepts, references |

## Getting Started

1. Read [Game Design Overview](docs/game-design-overview.md)
2. Review [Story Overview](docs/story-overview.md) — add your beginning storyline
3. Place existing art in `art/story/` or `art/concepts/`
4. Refine simulation specs in `tech/` as needed
5. Map learning to story in `content/learning-objectives.md`

All documents are marked [DRAFT] and meant for revision.
